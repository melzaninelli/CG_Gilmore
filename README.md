# CG_Gilmore
Projeto desenvolvido para a disciplina de Computação Gráfica, utilizando Three.js e Vite, inspirado no universo da série Gilmore Girls. A proposta é criar um ambiente 3D interativo que represente o charme e a atmosfera acolhedora de Stars Hollow, explorando modelagem 3D, iluminação, texturas, materiais e navegação em tempo real.
